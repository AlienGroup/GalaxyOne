# Alien Emergency Fund Loan Application System

## Overview
This project is a Flask-based web application for managing emergency loan applications. It provides a user-facing portal for applicants to apply for loans and track their application status, as well as an admin portal for reviewing applications, making decisions, and managing the loan process. The application includes features such as user registration/login, a loan calculator, file uploads for required documents, email notifications, and an electronic contract signing process.
